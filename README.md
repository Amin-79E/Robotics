# Robotics Practice

A collection of the code I write while learning robotics and embedded programming with Arduino. Each folder/file is a small, self-contained project, added as I go.

> **Status:** ongoing learning log. Projects are simple and get more complex over time.


## Hardware

- Arduino UNO R3 RFID learning suite (starter kit)
- Included modules: I2C 1602 LCD, RFID reader with keychain and card, DS1302 clock, 4x4 keypad, 8x8 dot matrix, temperature and humidity module, water level sensor, sound sensor, relay, servo, stepper motor with driver, joystick, infrared receiver and remote


## Software

- Arduino IDE
- Language: C/C++ (Arduino sketches).
